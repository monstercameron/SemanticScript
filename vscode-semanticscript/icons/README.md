# SemanticScript Icons

Icon assets used by the SemanticScript VS Code extension.

- `semanticscript-extension.png` is the 128x128 extension gallery icon.
- `semanticscript-extension.svg` is the editable source for the gallery mark.
- `semanticscript-file-light.svg` and `semanticscript-file-dark.svg` are the
  language icon fallbacks used by VS Code file icon themes.
- `semanticscript-icon-theme.json` defines the optional SemanticScript file icon
  theme for `.sscript`, `.sem`, `build.sscript`, and `build.sem`.
