# JavaScript Samples

JavaScript reference implementations for sample programs that also exist or are
being explored in SemanticScript.

## Contents

This folder includes small programs such as hello world, fizzbuzz, calculator,
todo list, inventory manager, event workflow, and larger stress-style examples
such as checkout saga and stack-language demos.

## Current Status

Reference/sample code only. These files are useful for behavior comparison,
translation experiments, and examples, but they are not part of the compiler
test harness unless a test explicitly invokes them.

## Maintenance

Keep sample filenames descriptive and stable. If a JavaScript sample is paired
with a SemanticScript sample, preserve comparable input/output behavior.
